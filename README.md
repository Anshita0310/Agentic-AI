# 🤖 Agentic AI

A collection of hands-on Jupyter notebooks exploring the foundations of Artificial Intelligence — from rule-based systems and Natural Language Processing to the inner workings of Neural Networks. Built as a learning-oriented project to understand how intelligent systems are designed and trained.

---

## Notebooks

### 1. `Rule_based_chatbot_with_NLP_.ipynb`
A step-by-step implementation of a **rule-based chatbot** enhanced with NLP techniques.

- Defines structured conversation patterns and intent-response mappings
- Uses NLP preprocessing (tokenization, pattern matching) to handle user input
- Demonstrates how rule-based systems respond to predefined triggers
- A practical introduction to the building blocks of conversational AI — and its limitations compared to learning-based approaches

### 2. `Understanding_Neural_Networks.ipynb`
A conceptual and hands-on walkthrough of **how neural networks work**.

- Covers the fundamentals: neurons, layers, weights, activation functions
- Walks through forward propagation and how a network produces an output
- Explores training concepts including loss functions and backpropagation
- Designed as a foundation for understanding the ML models that power modern AI

## Getting Started

### Prerequisites

- Python 3.8+
- Jupyter Notebook or JupyterLab

### Installation

```bash
# Clone the repository
git clone https://github.com/Anshita0310/Agentic-AI.git
cd Agentic-AI

# Install dependencies
pip install nltk numpy matplotlib jupyter

# Launch Jupyter
jupyter notebook
```

Then open either notebook from the Jupyter interface and run the cells in order.

## Learning Goals

This repo is designed to help you understand:

- How **rule-based AI** works and where it falls short
- How **NLP techniques** can make simple bots more robust
- The core math and intuition behind **neural networks**
- The progression from rigid rules → statistical models → learned representations that defines the evolution toward modern agentic AI
